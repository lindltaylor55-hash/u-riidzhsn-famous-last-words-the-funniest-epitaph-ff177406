# Famous Last Words: The Funniest Epitaph

One line of famous last words, carved as a tombstone epitaph — the funniest
possible send-off in 150 characters or fewer.

> Here lies a man who always wanted the last word. He finally got it. Nobody was listening.

The program in `main.ts` writes the epitaph from `entry.txt` to
`/output/entry.txt`, byte for byte.
